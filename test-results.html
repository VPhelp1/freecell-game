🚀 API Endpoints

GET /api/games/types # Список типів ігор POST /api/games/create # Створити нову гру GET /api/games/:id # Стан гри POST /api/games/:id/move # Зробити хід POST /api/games/:id/reset # Скинути гру DELETE /api/games/:id # Видалити гру GET /api/games/stats/overview # Статистика

📋 Приклад створення гри

curl -X POST http://localhost:3001/api/games/create \ -H "Content-Type: application/json" \ -d '{"gameType": "bakers_game"}' Відповідь: { "success": true, "data": { "gameId": "uuid-here", "gameState": { ... } } }

📋 Приклад ходу

curl -X POST http://localhost:3001/api/games/UUID/move \ -H "Content-Type: application/json" \ -d '{ "from": {"type": "tableau", "index": 0}, "to": {"type": "freeCell", "index": 0} }'
